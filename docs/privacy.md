# Delion Bot 隐私条款

本页说明你的数据存放在哪里，以及哪些内容会离开你的设备。使用本软件时的责任划分见[《Delion Bot 使用条款》](terms.md)。

最后更新：2026-11-20

## 1. 数据保存在本机

**本软件没有远程数据库，也不把你的数据上传给开发者**。你的对话、资料与各项设置都保存在你的设备上。界面不直接读写数据库与凭据文件，只通过预加载接口请求主进程。

应用数据目录（Electron 的 userData，Windows 上通常是 %APPDATA%\delion-bot）下：

- SQLite 数据库 delion.db：会话索引、笔记与文件的索引、通知、各项设置和配置向导的完成状态。旧版本写入的条款接受记录仍保存在本机。
- 对话的完整记录：pi/sessions 下的 JSONL 文件，由 Agent 内核写入；数据库里只有这些会话的索引。
- 其他文件：对话中发送的图片与文档附件副本（chat-media/）、远端项目的内容镜像（remote-context/）、非项目聊天文件的历史版本（chat-files/，以 Git 仓库保存 5 MiB 以下的文件，随会话一并删除）。文档副本保留供后续追问，启动时清理没有会话引用的图片与文档；未发送的文档附件在你移除时删除。
- 界面状态：Chromium 的 Local Storage（userData/Local Storage）里存着侧栏与各面板的折叠状态和宽度、已看过的更新版本、字号和聊天草稿。

同一目录下的加密凭据文件：

| 凭据文件               | 保存的内容                                     |
| ---------------------- | ---------------------------------------------- |
| llm-providers.bin      | 模型服务地址与 API Key                         |
| composio.bin           | Composio 项目密钥与会话配置                    |
| pipedream.bin          | Pipedream 客户端凭据、项目 ID 与已连接应用列表 |
| connector-provider.bin | 当前启用的连接器服务商                         |
| mcp-servers.bin        | MCP 服务器的命令、参数、环境变量、地址与请求头 |

工作目录（默认「文档/Delion Bot」，可在 设置 › 工作区 更改）中的文件：笔记的 Markdown 正文与其中的图片、导入的文件，以及导出到「预览导出」文件夹的 PDF。

可选文档解析组件保存在应用数据目录的 components/document-reading 下。文档读取任务的输入副本与提取结果保存在系统临时目录的 delion-document-reading 下，读取结束后清理；异常退出留下的任务会在下次准备文档时清理超过 24 小时的部分。

升级时保留旧版本的本地邮件与草稿。连接器需要重新授权。

## 2. 凭据如何保护

- **凭据文件用 Electron safeStorage 加密后写入，解密能力由操作系统保管**；系统不支持加密时，应用拒绝读写并给出提示。
- 写入先落临时文件再原子替换；旧文件无法解密时，先备份为「原文件名.unreadable-随机串.bak」再写入新内容，不因重新配置而删除。
- **API Key 与令牌只在主进程内使用**：界面拿到的模型服务配置不含密钥字段；连接器只返回账户标识、应用和状态；MCP 服务器只返回名称、连接方式与状态，不含命令、地址、环境变量与请求头。
- **密钥不进入模型消息**：请求时由主进程把 API Key 放进 HTTP 请求头，发给模型的内容是对话与资料文本。

## 3. 运行 Agent 时发送到模型服务的内容

**只有在你发送消息、让它继续执行，或在设置中检测密钥时，才会请求模型服务**。请求由主进程直接发出，界面不持有密钥。

- 系统提示词，以及已启用 Skills 的名称与描述索引。
- 你在 设置 › 自定义指令 中填写的全局指令（留空则不发送），它会随每次请求一并发出。
- 当前会话的历史消息；较早历史已生成摘要时，摘要一并发送。
- 本轮引用的资料内容（按需读取的笔记、课程文件、邮件等正文）、附件正文、你输入的文字与图片。
- 工具执行结果会随后续轮次继续发回同一服务。

这些内容发往 设置 › 模型供应商 中启用的地址。**数据保存在本机不等于在本机推理**：应答由你选择的模型服务产生，内容发出后如何保存由该服务决定，本应用不控制。

## 4. 本软件会联网的位置

| 去向                     | 触发时机与内容                                                                                                                                                                                                                                                             |
| ------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 模型服务                 | 你在 设置 › 模型供应商 中配置的地址；对话、历史摘要与密钥检测都请求这里。                                                                                                                                                                                                  |
| 模型目录                 | pi.dev：后台拉取 Pi 内置厂商的最新模型目录（约每 4 小时一次），请求只含厂商名与 Pi 版本，不含密钥与对话内容。                                                                                                                                                              |
| MCP 服务器               | 只连接你在 设置 › MCP Server 中添加的远程地址，携带你填写的请求头；Agent 调用其工具时，把工具参数发往该服务器。本地命令型服务器在本机运行，联网行为由该程序决定。                                                                                                          |
| Composio 与已授权的应用  | 配置、授权和调用工具时发送项目或账户标识、操作参数及结果。第三方账户凭据由 Composio 管理。                                                                                                                                                                                 |
| Pipedream 与已授权的应用 | 配置、授权和调用工具时发送项目或账户标识、操作参数及结果。第三方账户凭据由 Pipedream 管理。                                                                                                                                                                                |
| 远程项目                 | 只连接你在 设置 › 远程 中自行添加的 SSH 主机。                                                                                                                                                                                                                             |
| 联网搜索                 | 把搜索词发往你在 设置 › 内置能力 › 网络 中注册的搜索服务：Brave（api.search.brave.com）、Google（www.googleapis.com/customsearch）或你填写的自定义 JSON 端点（可带自定义请求头）。Delion Bot 不内置搜索服务，未注册时不发起任何搜索请求。                                  |
| 读取网页                 | 抓取模型指定的任意公网地址，只允许 http/https 与 80/443 端口；内网、环回与链路本地地址被拒绝，每一跳重定向都会重新做 DNS 校验。                                                                                                                                            |
| 文档解析组件             | 在「能力拓展」或 设置 › Skills 安装文档读取组件时，连接 www.python.org、github.com 及其发行文件域名、pypi.org 和 files.pythonhosted.org 下载 Python、uv 与解析依赖；下载请求不包含你的文档或应用凭据。解析在本机执行，模型读取正文与图片时仍会按「模型服务」条目发送内容。 |

联网搜索、读取网页等内置能力可在 设置 › 内置能力 中逐项关闭；少数被其他工具依赖的能力固定开启，在该页只读展示。

## 5. 本机记录了什么

**应用运行时不写日志文件**（开发模式的控制台输出只打印在终端，不落盘）。Agent 执行也不单独留档：一次执行的运行状态只存在于内存与界面（导航行上的运行标记），执行过程随对话正文一起写进会话文件（见第 1 节），数据库里的会话索引只记消息计数与最后更新时间。

凭据与密钥不写进会话记录，也不会作为上下文发给模型。

## 6. 本软件没有的功能

- **没有账号服务器**：不需要注册或登录 Delion Bot 账号，代码中也没有把数据上传到项目服务器的接口。
- **没有云同步**：换一台设备时，需要自行拷贝工作目录与应用数据目录。
- **没有使用统计与崩溃上报**：依赖中没有统计分析或崩溃上报的第三方服务，主进程的对外请求只有上面列出的几类。
