# 0023 Agent 权限管理与跨平台沙盒

- 状态：平台选型已确定，授权策略待确认
- 日期：2026-11-21

## 执行边界

Linux 本机及 Linux SSH 项目在执行端使用 bubblewrap 隔离挂载和网络，Landlock 约束文件访问，seccomp 约束系统调用。Windows 本地命令进入 WSL2 后使用同一 Linux 后端，仅映射获准目录，隔离 Windows 互操作、宿主套接字和盘符挂载。macOS 本地命令使用 Seatbelt（sandbox-exec）。执行端无法落实请求的限制时拒绝启动，并将原因返回给用户。

## 授权决定

宿主掌管授权记录和审批界面。每次操作按项目、执行端、会话、能力、资源及动作判定。未声明的能力默认拒绝。新项目建议默认允许只读项目文件，写入、命令执行、对外传输和外部服务操作需经用户授权。用户可拒绝、允许本次、允许本会话或保存项目授权。对外发送和删除外部数据建议每次确认具体目标与内容。一次性批准仅能消费一次，参数变更需重新判定。

直接文件读写、搜索、命令及其子进程都受项目目录和读写模式约束。项目内的链接不能扩大可访问范围。授予目录写入意味着在该目录中运行的已授权命令也能改写和删除文件。允许命令联网意味着该进程可发送其能读取的数据；授权界面应显示这个组合的实际影响。

宿主在网页访问、MCP 调用、连接器和 delion 领域命令产生副作用前检查授权。本地 stdio MCP 服务也需按其实际资源需求隔离启动。远端服务的授权绑定连接账户和具体工具，无法判断副作用的调用逐次确认。模型提供商通信沿用用户配置，工具使用的凭据留在持有该连接的宿主侧。Agent 无权代用户批准、编辑授权库或操作手动终端。

子 Agent 和后台任务继承父任务权限上限。项目切换不转移授权。撤销授权应拒绝尚未执行的操作并终止依赖该授权的受控进程；已经提交给外部服务的操作可能无法撤回。用户可在项目设置查看、收紧和撤销授权，并查看决定、时间、作用域和结果。审计记录避免保存凭据和原始敏感内容。

## 验收边界

分别在 Linux、WSL2、macOS 与远端 Linux 验证正常工作负载、越界读写拒绝、无授权联网拒绝及后端不可用时拒绝执行。宿主侧验证工具直调、领域命令、子任务、后台任务和外部服务均遵守审批与撤销，且工具返回的文本不能产生授权。
