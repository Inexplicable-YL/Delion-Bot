# 0023 Agent 权限管理与跨平台沙盒

- 状态：会话目录隔离、单次审批与同类授权已接入
- 日期：2026-11-21

## 当前实现

普通聊天和项目聊天默认自动批准。普通聊天使用独立的 `/privacy` 和 `/share`。前者保存中间文件，后者供用户和 Agent 交换文件。项目聊天使用 `/project`。受限文件工具经 Windows、macOS 和 Linux 的目录句柄访问已授权目录。读到的文件可进入模型上下文。

请求批准模式提供沙箱命令、联网和连接器。文件修改、带副作用的操作及无法判断为只读的工具调用须经批准，操作卡片替换聊天输入框。用户可允许本次、拒绝并留言给 Agent，或对同类操作始终允许：普通聊天的授权只在本会话内有效，保存在内存；项目聊天的授权写入项目，重启后仍有效。同类按能力区分：命令按程序名，git、npm、pnpm 等多子命令工具按程序名加子命令，管道与命令列表中的每个程序都须已获授权，含命令替换、复合语句、启动其他程序或删除文件的命令不提供该选项；文件修改不分路径；网页按主机；连接器按连接器与工具；Delion 操作按命令。普通聊天的宿主文件路径留在文件代理内。完全访问通过应用内确认窗口启用。远端项目由 SSH helper 执行。子 Agent 继承主会话的权限。切换权限需要等待当前回合结束，随后停止后台任务并重新载入会话。移动聊天会重新采用目标位置的默认权限。

自动批准模式放行公开网页搜索和抓取、已分类的连接器读取、文件读取，以及本地聊天目录或项目内的创建和修改。创建外部文件或目录需要目标父目录的授权。外部新建使用仅创建操作，已有文件保留。删除、外部修改、SSH 写入、非公开网络地址和无法确认效果的命令需要批准。简单的目录和文件命令通过文件代理执行。只使用工作目录内相对路径、不重定向写入、不执行其他程序的只读命令（如 ls、cat、head、grep、find、wc）直接运行。其余命令、SSH 写入和 Delion 操作的审批同样可选择始终允许，删除除外。

## 命令隔离目标

只读模式和自动批准使用相同的读取规则。模型可以读取文件、网页、技能和已分类的连接器。命令按操作和参数判断，常见 Git 状态、历史、差异及 GitHub PR、Issue 和工作流查询直接执行。无法确认只读的命令在只读模式下拒绝执行，在自动批准下请求批准。

请求批准模式经批准后，在本机或 SSH 对端以当前账户权限执行该命令。批准包括命令可访问的文件、启动的子进程和网络。先前的受限命令授权需重新确认。普通聊天的命令从临时目录启动，并通过 `/privacy` 和 `/share` 访问当前会话文件。无输入副本的项目命令从项目目录启动。SSH 的受限命令需要 `/usr/bin/bwrap` 及非特权用户命名空间。

## 授权决定

宿主掌管授权记录和审批界面。每次操作按项目、执行端、会话、能力、资源及动作判定。未声明的能力默认拒绝。用户可拒绝、允许本次、允许本会话或保存项目授权。对外发送和删除外部数据建议每次确认具体目标与内容。一次性批准仅能消费一次，参数变更需重新判定。

授予目录写入意味着在该目录中运行的已授权命令也能改写和删除文件。允许命令联网意味着该进程可发送其能读取的数据。授权界面应显示这个组合的实际影响。

### 受限模式的目录范围

- 项目会话的用户文件范围是当前项目根目录。远端项目以 SSH 对端的项目根目录为准。
- 独立聊天的用户文件范围是当前会话的 `chat-sessions/<会话 ID>/` 和 `chat-share/<会话 ID>/`。

宿主按会话身份约束文件写入、搜索、文件引用和受限命令输入。链接和路径别名不得扩大范围。宿主通过受控接口提供会话记录和附件。

### 读取范围外的文件

本地会话可通过 `read` 和 `ls` 使用绝对路径读取普通外部文件或列出目录。文件代理排除 Delion 数据、系统敏感位置和常见凭据路径。SSH 项目的文件工具以远端项目根为准。

宿主在网页访问、MCP 调用、连接器和 delion 领域命令产生副作用前检查授权。本地 stdio MCP 服务也需按其实际资源需求隔离启动。远端服务的授权绑定连接账户和具体工具，无法判断副作用的调用逐次确认。模型提供商通信沿用用户配置，工具使用的凭据留在持有该连接的宿主侧。Agent 无权代用户批准、编辑授权库或操作手动终端。

子 Agent 和后台任务继承父任务权限上限。项目切换不转移授权。撤销授权应拒绝尚未执行的操作并终止依赖该授权的受控进程；已经提交给外部服务的操作可能无法撤回。用户可在项目设置查看、收紧和撤销授权，并查看决定、时间、作用域和结果。审计记录避免保存凭据和原始敏感内容。

## 验收边界

分别在 Linux、WSL2、macOS 与远端 Linux 验证正常工作负载、越界读写拒绝、无授权联网拒绝及后端不可用时拒绝执行。宿主侧验证工具直调、领域命令、子任务、后台任务和外部服务均遵守审批与撤销，且工具返回的文本不能产生授权。

验证项目会话与独立聊天的目录边界，覆盖同级会话、链接目标、受保护路径、外部只读访问，以及拒绝后不执行命令。
