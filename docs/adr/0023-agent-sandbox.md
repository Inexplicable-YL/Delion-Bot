# 0023 Agent 权限管理与跨平台沙盒

- 状态：本地会话目录隔离和单次文件修改审批已接入
- 日期：2026-11-21

## 当前实现

本地聊天和项目会话默认只读。普通聊天使用独立的 `/privacy` 和 `/share`。前者保存中间文件，后者供用户和 Agent 交换文件。项目聊天使用 `/project`。受限文件工具经 Windows、macOS 和 Linux 的目录句柄访问已授权目录。请求批准模式逐次确认写入和编辑，项目内修改模式自动允许项目内写入。读到的文件可进入模型上下文。

通用命令、工具联网、连接器和宿主命令桥仅在完全访问模式可用。启用完全访问需要在宿主弹窗确认。已有的完全访问授权也需要重新确认。远端项目由 SSH helper 执行同一套受限文件操作，范围以远端项目根为准。子 Agent 继承主会话的权限。切换权限需要等待当前回合结束，随后停止后台任务并重新载入会话。移动聊天会重新采用目标位置的默认权限。

## 命令隔离目标

macOS 受限会话可运行单进程 Seatbelt 命令。文件代理将选中的输入文件复制到只读暂存区。命令通过标准输出返回结果，项目写入仍经过原有权限。请求批准模式逐次确认命令和输入列表。

受限模式启用命令前，执行端必须验证目录、网络、宿主服务和进程生命周期的隔离。候选方案包括 Linux 的命名空间、Windows 的 WSL2 和 macOS 的 Seatbelt。后端无法落实限制时拒绝启动。

## 授权决定

宿主掌管授权记录和审批界面。每次操作按项目、执行端、会话、能力、资源及动作判定。未声明的能力默认拒绝。新项目建议默认允许只读项目文件，写入、命令执行、对外传输和外部服务操作需经用户授权。用户可拒绝、允许本次、允许本会话或保存项目授权。对外发送和删除外部数据建议每次确认具体目标与内容。一次性批准仅能消费一次，参数变更需重新判定。

授予目录写入意味着在该目录中运行的已授权命令也能改写和删除文件。允许命令联网意味着该进程可发送其能读取的数据。授权界面应显示这个组合的实际影响。

### 受限模式的目录范围

- 项目会话的用户文件范围是当前项目根目录。远端项目以 SSH 对端的项目根目录为准。
- 独立聊天的用户文件范围是当前会话的 `chat-sessions/<会话 ID>/` 和 `chat-share/<会话 ID>/`。

宿主按会话身份决定目录范围，统一约束直接文件工具、搜索、文件引用与沙盒命令。目录范围和读写权限分别检查。链接和路径别名不得扩大范围。宿主通过受控接口提供会话记录和附件。命令仅额外获得运行所需的系统文件和隔离的临时目录。

### 读取范围外的文件

路径可作为申请目标。宿主在用户确认前拒绝读取或列出对应内容。路径不明确时，由用户在宿主文件选择器中选择文件或目录。审批显示发起会话、执行端、准确的文件或目录、只读范围和用途。模型会接收文件内容时，审批也应说明这一点。

默认按本次操作批准单个文件的宿主侧只读访问。确需处理多个文件时，用户可批准具体目录的只读访问，并明确是否包含子目录。命令确需读取该资源时，使用单独批准的只读授权启动新沙盒。拒绝后，Agent 可以用已有资料继续，或由用户选择导入所需文件。外部文件读取授权不附带写入、命令联网或连接器上传权限。

宿主在网页访问、MCP 调用、连接器和 delion 领域命令产生副作用前检查授权。本地 stdio MCP 服务也需按其实际资源需求隔离启动。远端服务的授权绑定连接账户和具体工具，无法判断副作用的调用逐次确认。模型提供商通信沿用用户配置，工具使用的凭据留在持有该连接的宿主侧。Agent 无权代用户批准、编辑授权库或操作手动终端。

子 Agent 和后台任务继承父任务权限上限。项目切换不转移授权。撤销授权应拒绝尚未执行的操作并终止依赖该授权的受控进程；已经提交给外部服务的操作可能无法撤回。用户可在项目设置查看、收紧和撤销授权，并查看决定、时间、作用域和结果。审计记录避免保存凭据和原始敏感内容。

## 验收边界

分别在 Linux、WSL2、macOS 与远端 Linux 验证正常工作负载、越界读写拒绝、无授权联网拒绝及后端不可用时拒绝执行。宿主侧验证工具直调、领域命令、子任务、后台任务和外部服务均遵守审批与撤销，且工具返回的文本不能产生授权。

验证项目会话与独立聊天的目录边界，覆盖同级会话、链接目标、项目子树，以及外部文件审批拒绝或到期后的读取行为。
