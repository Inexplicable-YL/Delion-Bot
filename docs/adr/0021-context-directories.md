# 0021. 通用会话经辅助目录看到资料

- 状态：已接受
- 日期：2026-11-15

## 背景

通用会话使用独立的工作目录，同时需要按需读取工作区的资料。

## 决定

- **工作目录不变**：通用会话一律用私有目录，新文件默认写在这里。资料页与首页新建的会话没有区别，只是标签打开的位置不同。
- **辅助目录**：core 提供 `registerContextDirectory({ id, label, directory })`，取代 `registerSessionScope`。workspace 模块登记资料根目录 `workspace/`。通用会话的系统提示列出这些目录及其名称，Agent 需要时自己检索。辅助目录与工作目录一样可读可写，不加约束。项目会话不带辅助目录。
- **@ 引用**：通用会话的候选是私有目录、资料根目录与模块登记的候选的并集。资料里的项目子树不进候选，避免代码仓库淹没列表。
- **协议**：通用会话只剩一种，`create-session` 去掉 `scope` 字段，删除 `chatScopeSchema`。移动端尚未发布，协议在 v1 内修改，不升版本；多传的 `scope` 会被 schema 忽略。

## 后果

- 首页与资料页的空会话不再按作用域区分，新建时互相复用。
