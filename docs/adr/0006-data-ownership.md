# 0006. 数据所有权与移动端的边界

- 状态：已接受
- 日期：2026-11-09

## 背景

移动端只转发 Agent 对话。如果不划清数据归属，两端会各自维护一份 Delion Bot 自己的数据，最终出现冲突。

## 决定

| 数据                       | 归属                 | 访问方式                            |
| -------------------------- | -------------------- | ----------------------------------- |
| 会话、Agent 运行、项目文件 | 桌面端 core          | 桌面端和移动端都通过 Agent 协议访问 |
| Todo、个人日程、笔记、草稿 | 桌面端的各个模块     | 只在桌面内部使用，不进入协议        |
| 邮件                       | 用户配置的邮件服务器 | 桌面端直接连接                      |

属于 Delion Bot 自己的数据，不能在移动端另起一份。

## 后果

- 移动端通过对话就能使用桌面端已启用的能力，因为 Agent 在桌面上运行。
- 如果以后移动端需要直接查看 Todo，需要新增一条记录，决定是否把它纳入协议。
