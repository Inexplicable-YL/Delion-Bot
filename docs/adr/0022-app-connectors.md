# 0022 外部应用连接器

- 状态：已接受
- 日期：2026-11-20

## 背景

当前邮箱模块直接访问 IMAP/SMTP，桌面端承担账户配置、同步、草稿和搜索。继续逐个实现外部应用会重复承担账户授权和服务适配。

## 决定

采用统一的连接器入口。用户从目录或聊天选择应用，在浏览器完成授权，随后可查看已连接账户、重新连接或断开。Agent 通过已有 MCP 能力发现并调用已启用应用的工具。

首版支持 Composio 与 Pipedream Connect 两家服务商，由服务商负责第三方账户授权与令牌管理。用户分别提供 Composio 项目密钥或 Pipedream OAuth 客户端凭据。Composio 以一个限定应用范围的会话提供全部工具；Pipedream 为每个已连接的应用建立一个 MCP 连接，访问令牌在主进程内按期续签。两家可以同时配置、授权和管理账户，但同一时间只启用一家，只有启用的服务商向 Agent 提供工具。

移除专用邮箱客户端、邮件搜索、命令和内置邮件 Skill。自定义 MCP 归入连接器入口。模型、SSH 项目、联网搜索及本地待办继续沿用各自的配置和生命周期。

## 后果

用户可通过同一入口接入邮件、日历及其他在线应用。外部工具调用及其返回内容会经过所启用的服务商。切换服务商后，需要在新服务商重新授权应用。原有邮箱账户需要重新授权，本地草稿不会自动出现在新账户中。升级时保留已有邮件数据，避免删除用户尚未发送的内容。
