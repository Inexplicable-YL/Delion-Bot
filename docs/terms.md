| 去向                                      | 触发时机                                     | 发送或接收的内容                                                                                                             |
| ----------------------------------------- | -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 你配置的模型服务地址                      | 你发送消息、让它继续执行，或在设置中检测密钥 | 系统提示、已启用技能的说明、自定义指令、会话历史与摘要、引用的资料与附件正文、你输入的文字与图片、工具执行结果；密钥在请求头 |
| Composio 与已授权的应用                   | 配置、授权或调用工具时                       | 项目或账户标识、操作参数及结果                                                                                               |
| 你添加的 SSH 主机                         | 你打开远程项目时                             | 工具执行、目录读取、文件读写与终端输入输出；密钥与口令由 ssh 及你的 ssh 配置管理，本软件不保存                               |
| 搜索服务（Brave / Google / 你填写的端点） | 你或 Agent 发起搜索时（该能力默认关闭）      | 搜索词                                                                                                                       |
| 任意公网地址                              | Agent 调用「读取网页」时                     | 请求由你的设备发出，目标站点可获知你的网络地址                                                                               |
